### D-001 — Выбор технологического стека и структуры репозиториев
- Дата: 2026-11-16
- Тип: решение
- Решение:
  1) Оба мобильных приложения (**uGym** и **uGym Business**) разрабатываются на **Flutter 3.x (Dart)** как отдельные проекты и отдельные git-репозитории.
  2) Общее сетевое ядро, форматтеры, маппер ошибок и реализация дизайн-системы **uCraft Design System 1.0 (Midnight & Cobalt)** выносятся в общий пакет `ugym_core`.
  3) Архитектура кода внутри приложения: `Feature-First` Clean Architecture (`domain` / `data` / `presentation`).
- Причина: единая кодовая база для iOS и Android, высокая скорость разработки и строгая статическая типизация Dart, привычная разработчику после PHP 8 / Laravel; переиспользование `ugym_core` гарантирует консистентность API-клиента и дизайн-системы uCraft.
- Затронутые разделы ТЗ: `uGym_Mobile_TZ.md` (раздел 2), `uCraft_Design_System.md` (раздел 21)
- Статус: принято

### D-002 — Переход на uCraft Design System 1.1 (UX and Layout Addendum)
- Дата: 2026-11-19
- Тип: решение
- Решение:
  1) Утверждено дополнение **uCraft Design System 1.1 — UX and Layout Addendum** (разделы 25–33 в `docs/specs/uCraft_Design_System.md`).
  2) Разделы 1–24 версии 1.0 (цветовые токены, типографика `Inter` + `Geist Mono`, отступы, радиусы, тени, иконки `Lucide`) остаются полностью в силе; при любом конфликте значения токена приоритет у v1.0.
  3) Правила композиции экранов `uGym` (разделы 26–33, включая спецификацию главного экрана `29.1 uGym — Home`):
     - Один доминирующий Hero-элемент на экран (`UcraftCardVariant.highlight`, фон `primarySubtle`, `radiusLg = 16`, `space5 = 20`, `elevation = 0`, статус-пилюля в правом верхнем углу, прогресс-бар по реальным данным) и одна основная кнопка (`Primary Button` во всю ширину под Hero-карточкой, например «Показать QR для входа»).
     - Повторяющиеся элементы (расписание «Сегодня в клубе», посещения, абонементы, платежи) рендерятся строками списка (`UcraftListSection` + `UcraftListRow`) с разделителями `1dp border`, а не стопкой карточек в рамке.
     - Статусы отображаются пилюлей `UcraftStatusPill` (всегда иконка `Lucide 16dp` + текст, никогда только цветом).
     - Вертикальный ритм: `space6 (24)` между секциями, `space3 (12)` внутри секции, `space1–space2 (4–8)` между заголовком секции и контентом, горизонтальный отступ экрана `space5 (20)`.
     - Нижняя панель навигации (`27.7 Bottom navigation (uGym)`): 5 вкладок, иконка `24dp` + подпись, активный пункт `primary`, неактивный `foregroundMuted`, фон `surface`, верхний разделитель `1dp border`, высота `64dp` + системный отступ.
- Причина: устранение визуальной «плоскости» экранов и выстраивание чёткой визуальной иерархии без изменения базовой дизайн-системы и токенов v1.0.
- Затронутые разделы ТЗ: `uCraft_Design_System.md` (разделы 25–33)
- Статус: принято
